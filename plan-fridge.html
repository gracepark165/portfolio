서비스 기획서 · 2인 팀 프로젝트 · 박여운: 팀 리더

냉집사

입력은 최소로, 먼저 먹을 재료는 앱이 알려 주는 냉장고 관리 웹 앱

1배경

냉장고 속 재료를 기억하지 못해 중복 구매하거나 먹을 시점을 놓칩니다. 기존 관리 앱은 모든 유통기한을 입력하게 해서, 관리보다 입력이 더 귀찮아 오래 쓰지 못합니다.

2문제 정의

대상장을 보지만 냉장고 속 재료를 다 기억하지 못하는 1~2인 가구
상황무엇이 남았는지 모른 채 장을 보거나, 저녁 메뉴를 정할 때
문제재료를 버리게 되고, 입력 부담 때문에 관리 앱을 포기한다
핵심 질문입력을 거의 하지 않아도 먼저 먹어야 할 재료가 한눈에 보이게 하려면?

3역할 분담

팀 구성2명
박여운팀 리더 — 프로젝트 방향 설정과 진행을 이끌고, UX/UI(사용자 흐름·사용성·화면 디자인)에 집중

4UX 원칙

  • 첫 사용 장벽 낮추기 — 예시 재료로 먼저 보여 주고, 내 재료로 시작할지 고르게 한다
  • 입력 부담 줄이기 — 사진 등록, 날짜는 확인만. 유통기한 대신 소비 목표(3일·1주·이번 달)
  • 우선순위가 한눈에 — 요약 카드, D-day 배지, 오늘 내일 해요 / 잊혀지는 중 / 싱싱해요 필터, 냉장·냉동·실온 탭
  • 결정을 대신해 주기 — 오늘 저녁 메뉴 하나와 “이걸로 할게요 / 다른 메뉴” 두 버튼
  • 기록은 한 번 탭 — 다 먹었어요 / 조금 남았어요 / 버렸어요
  • 친근한 톤 — 말을 거는 문구, 냉장고 캐릭터, 밝은 블루 톤

5사용자 흐름

예시로 둘러보기 / 내 재료로 시작→사진으로 재료 등록→소비 목표 선택→먼저 먹을 재료 · 메뉴 제안→먹은 뒤 한 번 탭으로 기록

6화면 구성

하단 탭내용
냉장고요약 카드, 오늘 저녁 메뉴 제안, 보관 위치 탭과 상태 필터, 재료 목록
영상 확인메뉴 관련 영상
장보기 올리기장 본 재료 등록
이번 주한 주 소비 계획

7핵심 기능과 검증 기준

기능내용검증 질문
재료 등록사진 → 품목·날짜 확인·수정1분 안에 끝나는가
소비 계획3일·1주·이번 달 목표 선택날짜 입력 부담이 줄어드는가
우선 소비먼저 먹을 재료 목록과 알림알림이 소비로 이어지는가
재고 반영다 먹었어요 / 조금 남았어요 / 버렸어요재고가 최신으로 유지되는가
메뉴 도움보유 재료 활용 메뉴 추천식재료 소진에 기여하는가
